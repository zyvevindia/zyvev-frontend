# Trusted brand presence playbook

EVSavari’s public presence is **calm, useful, and trustworthy** — not promotional noise.

## Principles

1. Share specific compare or guide URLs with context  
2. Let practical content earn return visits  
3. No spam, incentives, or engagement loops  
4. Brand familiarity comes from repeated helpful research sessions  

## Ops signals (`/admin/public-beta-ops`)

| Panel | Healthy |
|-------|---------|
| Users remembering EVSavari? | Repeat guide/compare entry |
| Strongest trusted-entry journeys | Guide → compare with depth |
| Most durable authority discovery | Consistent paths week-over-week |
| Weak public trust journeys | Guide entry without compare follow-through |
| Most trusted compare-sharing paths | Share → compare completion |

## Metrics

- `trustedBrandEntryQuality`  
- `repeatBrandDiscovery`  
- `authorityRecallPersistence`  
- `returnUserBrandFamiliarity`  

## Scaling gate

Expand public promotion only when `usersRememberingEvsavari` is true and `weakPublicTrustJourneys` is shrinking.
