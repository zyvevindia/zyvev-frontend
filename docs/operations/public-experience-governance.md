# Public experience governance

Cadence for **public polish**, **trust consistency**, **authority execution**, and **calm conversion quality**.

## Review cadence

| Review | Cadence | Owner | Surface |
|--------|---------|-------|---------|
| Public UX & journey clarity | Weekly | content-ops | `/admin/content-usefulness` |
| Recommendation trust consistency | Weekly | editorial-trust | `/admin/recommendation-refinement` |
| Authority content execution | Weekly | seo-editorial | `/admin/seo-authority` |
| Conversion trust (reassurance) | Weekly | conversion-ops | `/admin/conversion-refinement` |
| Repeat-user confidence | Weekly | beta-ops | `/admin/public-beta-ops` |
| Media & visual trust | Monthly | media-ops | `/admin/media-health` |

## Weekly snapshots

`evsavari-public-experience-weekly-v1` — public experience maturity, calm UX trend, trust consistency evolution.

## Gates

### `readyForDisciplinedExpansion`

Inherited from `buildTrustedScalingMaturitySummary()` plus public polish signals:

- `calmUxQualityTrend` = `calm`  
- `trustConsistencyTrend` = `stable`  
- `publicExperienceMaturity` = `polished` (stretch; `building` is normal early)  

### Public quality review (weekly)

1. Users consistently trusting EVSavari?  
2. Authority usefulness compounding?  
3. Recommendations remaining useful?  
4. Public experience polished?  
5. Ready for disciplined expansion?  

## Rollback discipline

| Trigger | Action |
|---------|--------|
| `weakTrustConsistency` = weak | Pair-level editorial calibration |
| `weakDiscoveryConsistency` = weak | Pause new internal links; fix orphans |
| `lowTrustConversionPersistence` elevated | Review reassurance copy only |
| `weakUsabilityPersistence` = persistent | Guide clarity pass before SEO expansion |
