# Real-world authority growth plan

Session-level learning for EVSavari controlled public beta — usefulness and realism first.

## Content priorities

1. Apartment charging reality
2. Ownership practicality and running cost
3. Real charging expectations (home + society)
4. Beginner EV education
5. Family suitability
6. Long-distance usage patterns
7. Real-world charging behavior (not spec sheets)

## Signals to watch

| Signal | Admin | Action |
|--------|-------|--------|
| `contentTrustTrend` | Content usefulness | Improve existing guide copy |
| `authorityUsefulnessScore` | Content usefulness | Deepen compare-support links |
| `weakPracticalContentClusters` | SEO authority | Editorial review, no new URLs |
| `compareSupportContentGaps` | SEO authority | Add rail links on compare only |

## Rules

- No AI article farms or thin-content scaling.
- No keyword stuffing or spam SEO.
- Compare ↔ guide linking before new pages.
- Guide ↔ compare return paths via `buildGuideToCompareDiscoveryLinks()`.

## Cadence

- Bi-weekly: weak practical clusters + low-engagement pages.
- Weekly: usefulness feedback rate in buffer.
- Before acquisition scale: `authorityUsefulnessCompounding` must be Yes in public beta ops.
