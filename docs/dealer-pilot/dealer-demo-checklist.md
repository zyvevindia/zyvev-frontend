# Dealer demo checklist

Use during an in-person or video demo (20–30 minutes).

## Before the call

- [ ] Pilot dealer account live with ≥1 listing
- [ ] Sample compare URL ready (two pilot models)
- [ ] WhatsApp sales number configured (`VITE_WHATSAPP_SALES_NUMBER`)
- [ ] Screen share: buyer site + dealer dashboard tabs

## Demo flow

### 1. Buyer discovery (5 min)

- [ ] Open a **city EVs** or **compare guide** page for pilot metro
- [ ] Show ranked recommendations and methodology panel
- [ ] Click **WhatsApp** — show pre-filled vehicle + page context
- [ ] Open **full compare tool** from a compare guide

### 2. Vehicle detail (5 min)

- [ ] Open a **family page** (`/cars/{slug}`)
- [ ] Switch variant — URL uses `?variant=` (canonical stays on family)
- [ ] Show **Request callback**, **Test drive**, **WhatsApp**, **Compare**

### 3. Compare tool (5 min)

- [ ] Add two pilot models to compare
- [ ] Submit **callback** form (optional: use test number)
- [ ] Show spec table and trust signals

### 4. Dealer dashboard (10 min)

- [ ] Log in at `/dealer`
- [ ] **Leads** tab: new lead, mark read, status pipeline
- [ ] **WhatsApp** from lead row — context preserved
- [ ] **Inventory**: edit listing, toggle availability
- [ ] **Analytics** (if enabled): views and lead count

### 5. Close (5 min)

- [ ] Recap SLA (4 business hours on new leads)
- [ ] Share ops WhatsApp for listing issues
- [ ] Confirm pilot scope: metro + 3 models
- [ ] Schedule week-1 check-in

## Success signals

- Dealer completes profile and one listing without ops help
- Dealer responds to a test lead within SLA
- Dealer understands difference between form lead vs WhatsApp intent
