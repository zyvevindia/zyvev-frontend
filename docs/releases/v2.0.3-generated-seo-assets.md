# v2.0.3 – Generated SEO Assets

**Release ID:** R-GEN  
**Priority:** P1  
**Tag (planned):** `v2.0.3-generated-seo-assets`  
**Status:** Ready for engineering approval — **not committed**

---

## Executive Summary

This release synchronizes **158 tracked generated SEO artifacts** with the latest build-pipeline output. Diffs are **timestamp / lastmod only** — no editorial content, routing, or schema changes.

Production already regenerates these files on every Vercel deploy via `prebuild` (`content:generate` → `build:sitemaps`). Committing R-GEN is a **repository hygiene** action: it clears ~158 dirty working-tree files and aligns `main` with what production builds emit.

**No feature development. No architecture redesign. No runtime code changes.**

---

## Business Value

These assets are the crawlable surface of EVSavari’s SEO engine. Syncing them keeps git honest and local/dev environments consistent with production.

| Capability | What it enables |
|------------|-----------------|
| **Search indexing** | Google and other crawlers discover ~477 URLs via sitemap index |
| **Landing discoverability** | Brand, price, use-case, city, compare, and authority pages remain indexed |
| **Google crawl efficiency** | Fresh `lastmod` signals reduce wasted crawl budget on stale dates |
| **Canonical consistency** | JSON embeds canonical paths; sitemaps list discovery URLs only |
| **Schema / metadata consistency** | Editorial JSON feeds `DiscoverySeoPage` + `SeoHead` pipeline |
| **Page generation** | SPA loads `/seo-data/{slug}.json` for guide and discovery content |
| **SEO performance** | Sprint 2.7 GSC readiness already certified; this keeps artifacts current |
| **Future AI discoverability** | Structured editorial JSON is reusable by agents and recommendation systems |

In plain English: **this release does not add new pages — it keeps the map of existing pages accurate and the repository clean.**

## Architecture Summary

```
scripts/generate-content.mjs  →  public/seo-data/** + content-manifest.json
                              →  src/content/generated/manifest.js
scripts/build-sitemaps.mjs    →  public/sitemap.xml + public/sitemaps/*.xml
                              →  public/sitemap-manifest.json (+ robots.txt when changed)
npm prebuild                  →  runs both before vite build (Vercel production)
```

| Principle | Status |
|-----------|--------|
| Editorial generation SSOT | `generate-content.mjs` |
| Sitemap generation SSOT | `build-sitemaps.mjs` only |
| Runtime consumers | `discoveryLoader` → static `/seo-data/*.json`; `slugMap` merges `manifest.js` |
| Circular deps | None (ordered soft dependency via prebuild) |
| Runtime code in this release | **None** |
