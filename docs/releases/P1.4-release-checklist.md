### 4. Verify CI

- [ ] Push baseline commit; confirm **CI** workflow green on Linux
- [ ] Confirm pipeline order:
  1. Install dependencies (`npm ci`)
  2. Production build
  3. Smoke tests (post-launch + ingestion)
  4. Playwright browser install (Chromium, Firefox, WebKit)
  5. Functional E2E (`test:e2e`)
  6. Visual inventory verification (`--require-webkit`, 168 PNGs)
  7. Visual regression (`test:visual`, 168 tests)
  8. Artifact upload on failure
- [ ] Job timeout: **120 minutes** (appropriate for full matrix)
