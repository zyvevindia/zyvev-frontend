# User value content playbook

Content exists to help users make **better EV decisions repeatedly** — not to inflate page count.

## Focus topics

Apartment charging, ownership practicality, running cost, beginner guidance, charging reality, family use, long-distance use, buying decisions, charging myths, ownership decision support.

## Ops review (`/admin/content-usefulness`)

| Panel | Action |
|-------|--------|
| Most practically useful guides | Deepen editorial accuracy |
| Highest-value compare journeys | Strengthen compare ↔ guide links |
| Most useful ownership guidance | Align with ownership realism ops |
| Weak practical guidance | Fix or consolidate |
| Most revisited practical content | Maintain freshness |

## Value signals

- `practicalValuePersistence`  
- `ownershipGuidanceUsefulness`  
- `chargingGuidanceUsefulness`  
- `compareUsefulnessDurability`  
- `authorityMemorabilityTrend`  

## Rules

- Realism-first, usefulness-first  
- No AI article farms or thin SEO  
- Human-governed calibration only
